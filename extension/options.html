Connect this browser to AgentGuard

Use a dedicated AgentGuard agent and a short-lived browser token. The permanent operator API key and Supabase service key never belong in the extension.

Setup flow

  1. Create an AgentGuard agent with the submit_prompt permission.
  2. Use the protected control-plane API to issue a browser token for that agent.
  3. Paste the token here, enable protection, and reload the supported AI tab.
